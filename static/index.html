安全总览

为 Web 应用建立一道安全边界

集中查看访问情况、管理防护策略，并追踪被拦截的请求。

国家归属来自离线 IP Geolocation by DB-IP（CC BY 4.0），表示 IP 登记归属，不能确定访问者实际位置。外部 IP 指可公网路由的来源 IP；不信任客户端自行填写的 X-Forwarded-For。

接入指引

  1. 在「站点配置」填写被保护应用的 HTTP / HTTPS 源站地址。
  2. 先使用观察模式验证正常业务，再切换为拦截模式。
  3. 将用户访问入口指向 WAF 的 8300 端口，并限制用户直接访问源站。

这是基础版本，生产接入前需完成规则调优、TLS 配置和压力测试。

被保护站点

证书加载

已配置域名加载 HTTPS 证书

先在“HTTPS 证书库”页签上传证书，再按已配置的域名选择对应证书。列表仅提供有效且覆盖该域名的证书。启用 HTTPS 并保存后加载，通过 SNI 选择证书，完成 TLS 解密卸载及 WAF 检测。

域名与后端源站

受保护域名后端源站（每行一个，最多 16 个）

每个域名可配置独立的 HTTP / HTTPS 源站池，多个源站轮询转发；精确域名优先于通配符。GET / HEAD / OPTIONS 连接建立失败时切换下一源站，其他请求不重试。源站保留访问域名 Host。

复杂匹配规则

每条规则组合匹配域名、访问端口及路径，可配置多个后端。优先级数值越大越优先；同优先级精确域名优先，再按最长路径匹配。端口留空表示任意端口；无规则命中时使用域名源站池及默认源站。

蜜罐配置

仅转送攻击特征及自定义拦截规则命中的请求，保留请求路径、查询和正文，不转送 Cookie 和认证头。蜜罐故障时继续拦截；限流、非法域名、超大请求和业务端口策略不转送。镜像旁挂与透明串联不使用此代理功能。

请求频率、请求体大小和方法限制始终生效。HTTPS 源站默认验证证书。

HTTPS 证书库

自动识别 PEM、DER、PKCS#7（P7B/P7C）、PFX/P12，并自动整理证书链、转换为可加载格式。PFX/P12 或包含私钥的合并 PEM 无需另选私钥；加密文件请填写证书密码。镜像旁挂和透明串联不解密 HTTPS。

密码仅用于本次导入，成功后清空。

系统防护规则

按业务需要开关规则。特征检测可能出现误报或漏报，建议先观察验证。

自定义防护 / 黑白名单

多个条件同时满足才命中；优先级数字越小越先执行，自定义规则按顺序首条命中生效。紧急拦截独立于基础检测开关和观察模式。白名单跳过攻击特征检测，域名、限流、请求大小和方法限制继续生效。镜像旁挂只审计。

新增自定义防护规则

留空的条件不参与匹配；至少填写一个条件，或明确选择匹配全部请求。保存立即生效，命中记录可在“访问审计”查看 CUSTOM 规则编号。

策略名称绑定目标状态 / 阈值操作

CC 防护

按真实连接来源 IP 统计 HTTP/HTTPS 请求，超过阈值临时封禁，自动到期恢复。独立于观察模式及攻击特征开关，命中返回 429。

仅对匹配绑定目标的请求执行 CC，目标 IP 指 WAF 接收连接的实际本地 IP，不是访客 IP 或源站 IP。基础的“每 IP 每分钟请求数”仍生效，白名单不绕过 CC。计数按进程保存，重启或策略修改会重置；HTTP 与 HTTPS 进程独立计数。前置代理场景按代理 IP 统计。镜像旁挂与透明串联不使用此入口策略。

策略名称绑定目标状态 / 阈值操作

HTTP/HTTPS 业务端口防护

自动保护 WAF 的 HTTP 及已启用的 HTTPS 监听入口，配置来源访问控制与正在处理的 HTTP 请求并发上限。管理入口不受限制。

禁止来源优先于允许来源。填写允许来源后，其他来源均拒绝（403）；并发超限返回 429 或 503。每个入口进程独立统计，包括上传和源站响应阶段，不统计空闲 TCP 连接。此功能不修改 Ubuntu 防火墙，不提供 SYN/UDP 洪泛防护，不影响其他主机端口。

访问审计

仅记录请求元数据，不保存请求体、查询参数、Cookie 和认证信息。时间以浏览器本地时区显示。国家数据：IP Geolocation by DB-IP。

数据库配置

勾选可查看已保存的连接密码。

更换数据库后可点击“数据初始化”，为页面所填的数据库创建 WAF 表结构和默认防护配置，保留已有数据。PostgreSQL 数据库本身需预先创建，账号需有建表权限；初始化不迁移历史数据，也不自动切换当前存储。

数据库切换操作说明

更换存储需先保存连接配置，再在 Ubuntu /opt/waf 停服并执行迁移；目标已有业务数据时拒绝覆盖。

docker compose stop waf
docker compose run --rm --no-deps --entrypoint python waf -m waf.switch_database
docker compose up -d --no-build --pull never waf

数据库运行参数

运行参数保存后立即生效。PostgreSQL 使用连接等待时间作为 SQL 执行超时，WAL 检查点仅适用于 SQLite。本地开发模式保持独立 SQLite。

日志转发配置

转发全部访问、防护、旁挂观察、错误及管理操作审计记录。首次启用从现有历史记录开始发送，随后持续转发新增记录。密码、Cookie、请求体和数据库内容不包含在日志中。

字段：{id}、{created_at}、{request_id}、{ip}、{method}、{path}、{action}、{rule_id}、{status}、{hostname}、{platform_name}。用 {{ 和 }} 表示字面花括号。每条日志为一行，字段中的换行将转义。

TCP/TLS 使用换行分帧；TLS 使用系统信任链，证书须包含接收 IP。UDP 发送成功不代表送达。TCP/TLS 失败后重试，可能重复，接收端可按 hostname 和 id 去重。

镜像旁挂 / 透明串联部署


正式部署使用 Ubuntu + Docker。容器共享宿主机网络，管理 IP、镜像口和透明桥接均作用于 Ubuntu 宿主机网卡。保存旁挂或串联配置后，容器自动启动对应数据平面；未成功启动时不会显示为防护已生效。


Ubuntu 上在项目目录启动：


bash start.sh


管理 IP 应用后执行 docker compose restart waf 更新监听地址。数据平面异常退出时，管理页面继续可用；修正配置并保存或重启容器后重试。Windows 仅用于本地开发，不提供镜像和透明桥接驱动。


当前数据平面检测明文 HTTP/1.x（TCP 80、8080）。HTTPS 加密内容、HTTP/2、HTTP/3 不在检测范围，需额外 TLS 解密组件。串联支持软件桥接，停止后桥接拆除，不能代替硬件断电旁路。详细安装和接线说明见 README。
