# 蜜罐地址配置

在“站点配置”菜单的独立“蜜罐配置”页签中，勾选“启用蜜罐转送”，填写独立蜜罐的 HTTP/HTTPS 地址，例如 `http://192.168.1.100:8080`，点击“保存蜜罐配置”。地址不能包含路径、查询参数或账号密码。配置持久化到当前 SQLite/PostgreSQL 数据库，保存后无需重启。

默认关闭。反向代理的 HTTP 和 HTTPS 入口中，攻击特征在拦截模式下命中，以及自定义拦截规则命中时，向蜜罐转送原始方法、路径、查询和请求正文，正常请求仍访问原来的源站。观察模式的特征命中继续转发原源站。

蜜罐接收 `X-Forwarded-For`、`X-WAF-Request-ID` 和 `X-WAF-Rule`，用于关联来源与规则。不转送认证头和 Cookie；正文、查询仍可能包含业务敏感信息，请将蜜罐部署在独立隔离环境。不会自动安装蜜罐服务。

蜜罐响应总时限 5 秒、上限 2 MiB，不跟随重定向，不向访客下发蜜罐 Cookie。连接失败、超时、重定向、5xx 或超大响应均回退原拦截响应，不访问真实源站。审计仍计入“已拦截”，规则后缀 `:HONEYPOT` 表示成功转送，`:HONEYPOT_FAILED` 表示转送失败；审计状态码保留原拦截状态码。

非法域名、请求限速、超大请求、方法限制和业务端口策略的拒绝不转送。镜像旁挂和透明串联不使用此代理功能。蜜罐地址不能指向 WAF 自身入口。
