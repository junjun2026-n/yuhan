# HTTPS 证书与域名防护

「站点配置」菜单分为「站点配置」「HTTPS 证书库」两个页签。在站点页签配置源站、受保护域名和 HTTPS 入口，在证书库页签上传证书及查询状态。页签切换保留草稿；上传后返回站点页签选择绑定并保存才能加载。

1. 在「受保护域名」每行填写一个域名，例如 `www.example.com`。`*.example.org` 仅匹配 `app.example.org` 这一层，不匹配根域名或 `a.b.example.org`。中文域名会转换为 IDNA。填写后，HTTP 和 HTTPS 入口均拒绝未配置域名及直接 IP 访问，审计规则标记为 `DOMAIN`。留空兼容原有任意 Host 接入。
2. 源站填写固定 HTTP/HTTPS 地址，例如 `http://192.168.17.128:8080`。所有配置域名共用这个源站及防护策略；源站会收到原始 Host 和 WAF 设置的 X-Forwarded-Host / X-Forwarded-Proto。HTTPS 源站默认校验证书。
3. 在「HTTPS 证书库」的「证书对应域名」下拉框选择已配置域名，再选择证书文件及所需私钥，点击「上传证书到证书库」。系统按文件内容自动识别 PEM、DER、PKCS#7（P7B/P7C）、PKCS#12（PFX/P12），无需手动转换。PFX/P12 或合并 PEM 自带私钥时不必另选私钥；PEM、DER、PKCS#7 证书通常还须提供 PEM/DER 私钥。加密 PFX/P12 或私钥需填写证书密码，可切换显示；密码仅在本次导入中使用，成功后清空，不写入审计或数据库。证书文件上限 1 MiB，独立私钥上限 64 KiB。系统匹配私钥与叶证书、去重并排序证书链，转换为内部 PEM 格式。上传成功后会回填该域名的证书绑定，须再保存站点配置才加载。也可选择“仅上传到证书库，暂不绑定域名”。域名选项来自上方“受保护域名”，未填写时会提示先配置。上传证书不匹配所选域名时提示错误，已有绑定保留。支持常见 RSA / EC 证书；证书须在有效期内、私钥匹配，并包含域名 SAN。私钥不回显；导入后以未加密 PKCS#8 PEM 保存在受限权限的 TLS 目录，供服务加载。
4. 在「证书加载」中，按已配置的域名选择下方证书库中的证书。下拉列表仅提供在有效期内且 SAN 覆盖该域名的证书；无匹配项时先上传对应证书。每个域名须明确选择，一张多域名或通配证书可以供多个域名使用。勾选「启用 HTTPS 防护入口」，设置端口，保存站点配置后加载。默认端口 8443；可使用空闲 443，不能使用 8300、8301。多个证书共用一个端口，握手时根据客户端 SNI 选择，精确域名优先于通配符。未知 SNI 域名拒绝握手；不发送 SNI 的旧客户端使用第一个受保护域名的证书，HTTP Host 仍须满足域名防护规则。所有域名仍共用同一源站。旧配置中的默认证书会在页面上按域名回显，保存后转为明确绑定。
5. 点击「刷新 HTTPS 状态」确认运行中。将 DNS A 记录指向 WAF 接入 IP，开放对应防火墙/NAT 端口，然后访问 `https://www.example.com:8443`；使用 443 时可省略端口。域名解析及公网证书需要自行提供，系统不自动申请或续期证书。

证书绑定保存后入口自动重载，现有 HTTPS 连接可能短暂中断；HTTP 8300 与管理 8301 保持运行。上传只添加到证书库，不自动加载或改变已有域名绑定。续期时上传新证书，再将相关域名切换到新证书并保存。端口冲突时显示启动失败，不会接管宿主机其他服务；修正端口或配置后保存重试。若配置未变但启动失败，可重启 WAF 容器重试。未上传正式证书时不默认开启 HTTPS。

证书与私钥存放在宿主机 `/opt/waf/runtime/tls/<内容标识>/`，私钥权限 600，目录 700；应连同数据库连接配置、数据库备份一起安全备份。SQLite / PostgreSQL 均存储证书引用与防护策略，证书文件需单独保留。旧证书文件保留以便恢复，不自动删除。

HTTPS 防护由反向代理终止 TLS 后进行与 HTTP 相同的检测和审计，最低 TLS 1.2。镜像旁挂和透明串联仍仅检测现有明文 HTTP 流量，不因上传证书自动解密第三方 HTTPS。管理页面 8301 的协议保持现状。
